Privacy policy

AgenticLab · last updated 2026-11-02

Who uses AgenticLab

AgenticLab is a private automation project used by a single person, its owner, who is also its developer. It has no other users, no public sign-up and no advertising.

Google user data accessed

With the owner's consent, given through Google's OAuth screen, AgenticLab accesses the owner's own Google account only, through two separate authorisations.

No other Google account and no other Google service is accessed.

How the data is used

Email, calendar and task data are used only to carry out the owner's own requests and routines: summaries, answers to questions about the owner's mail, agenda and tasks, a weekly planning view, reminders of birthdays and events the owner cares about, digests on a schedule the owner sets, and watchers on senders the owner chooses. Google user data is:

  • not sold;
  • not used for advertising;
  • not used to build profiles of anyone;
  • not used to train general-purpose artificial-intelligence or machine-learning models.

AgenticLab's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage, retention and deletion

Calendar events are kept for the coming weeks only and refreshed every few minutes: an event deleted in Google disappears at the next refresh. Messages read for a request, and the results produced, are kept in the owner's database on the owner's server and in its encrypted backups, so the owner can review past results. The owner can delete them at any time. Access tokens are stored on the server, each readable only by the component that calls the corresponding Google service.

Access can be revoked at any time at myaccount.google.com/permissions. AgenticLab then stops accessing the revoked service immediately.

Security

The server accepts no inbound connection except administration over SSH; the owner's web interface is reached only through an outbound tunnel, behind an identity check and a passkey. Each component holds only the credentials it needs. Every change made in Google Tasks and every action of the web interface is recorded in an audit log that the components cannot rewrite.
