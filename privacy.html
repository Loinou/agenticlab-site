Privacy policy

AgenticLab · last updated 2026-10-29

Who uses AgenticLab

AgenticLab is a private automation project used by a single person, its owner, who is also its developer. It has no other users, no public sign-up and no advertising.

Google user data accessed

With the owner's consent, given through Google's OAuth screen, AgenticLab accesses the owner's Gmail account with the read-only scope https://www.googleapis.com/auth/gmail.readonly. It can:

  • search messages;
  • read message headers, text and attachments.

It cannot send, delete, label or modify messages. No other Google account and no other Google service is accessed.

How the data is used

Email content is used only to carry out the owner's own requests: summaries, answers to questions about the owner's mail, digests on a schedule the owner sets, and watchers on senders the owner chooses. Google user data is:

  • not sold;
  • not used for advertising;
  • not used to build profiles of anyone;
  • not used to train general-purpose artificial-intelligence or machine-learning models.

AgenticLab's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage, retention and deletion

Messages read for a request, and the results produced, are kept in the owner's database on the owner's server and in its encrypted backups, so the owner can review past results. The owner can delete them at any time. Access tokens are stored on the server, readable only by the component that calls Gmail.

Access can be revoked at any time at myaccount.google.com/permissions. AgenticLab then stops accessing Gmail immediately.

Security

The server accepts no inbound connection except administration over SSH. Each component holds only the credentials it needs. Every access to Gmail is recorded in an audit log that the components cannot rewrite.
